# L1.4 trustworthy quality evidence — implementation record (2026-10-26)

Status: deterministic part implemented; **real-model evaluation and human review NOT RUN (blocked: no provider key in this environment)**.

## Implemented (F07)
- `tests/helpers/r2-scoring.ts`:
  - A negation now cancels a claim only inside its own clause, so "We don't groom cats, but yes, we groom horses for 90 dollars" is a fabrication (previously any sentence containing a negation was dropped before checking).
  - Decline detection needs a first-person limit or a hand-off ("I can't...", "no record", "connect you with a team member"); a stray contraction ("won't take long", "don't worry") no longer counts as a decline.
  - A required fact counts only if it is not negated ("We do not open at 9 am" no longer satisfies "9 am").
  - `escalate` turns must also be free of leaks and fabrications.
  - `summarize` takes the required categories: one with no evaluable results fails the gate instead of disappearing.
  - `evaluateGate`: at least 3 repetitions; exactly one observation per planned case x repetition x turn (no gaps, duplicates or strays); at least 80% of a category's planned turns evaluable (e.g. a tool case where the tool was never called is inconclusive); thresholds unmet or run invalid means the gate fails.
- Live runner (`tests/integration/ai-decision-quality-live.test.ts`): gates on `evaluateGate` for the `evaluation` and new `holdout` sets; `development` stays tuning-only. Output includes `valid` and `problems`.
- Fresh holdout (`tests/integration/r2-cases/holdout.json`, manifest with SHA-256, frozen 2026-10-26): 45 cases, 5 new domains (bike shop, florist, tutoring, cinema, laundry), all seven categories, disjoint from development/evaluation; authored before any scoring run on it. A unit test fails if the file changes without a deliberate re-freeze.
- Human rubric and sampling protocol: `docs/r2-human-review-rubric.md`.

## Not done / limitations
- **Real-model evaluation on the holdout (criterion open, BLOCKED):** needs `OPENAI_API_KEY` (and an owner decision on model, repetitions >= 3 and spend). Command once available (no `OPENAI_BASE_URL`): `R2_SET=holdout R2_REPS=3 R2_OUT=<file> npx vitest run --config vitest.integration.config.ts tests/integration/ai-decision-quality-live.test.ts`.
