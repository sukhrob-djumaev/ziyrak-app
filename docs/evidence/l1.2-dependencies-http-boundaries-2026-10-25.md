- Authenticated routes (`channels/[type]`, `chat`, many `request.json()`) still unbounded beyond the 3 MB proxy cap; cap applies globally.
  A body over 3 MB on any route is truncated by Next and will fail JSON parsing - check for legitimate large authenticated uploads.
- Slow-body exposure beyond the route deadline depends on Node `requestTimeout` / the real edge (not inspected).
- `withDeadline` stops waiting on DNS but the underlying lookup continues in the background.
- Oversize SMS/phone/Telegram bodies are logged as errors and ACKed (harmless noise).
