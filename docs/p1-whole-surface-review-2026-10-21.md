# P1 whole-surface independent security review (2026-10-21)

Three independent, read-only agent reviews of main `267ad99` (plus one test commit), split by slice:
(1) identity, workspace selection, platform operators and support access; (2) connection-restricted
members and resource scoping, including the member access editor; (3) all delayed work and every job
type. They read source and tests; they did not run tests, so no test was mutation-checked by them.
These are agent reviews, not human ones. Dispositions below are on branch `p1-closure`.

## Result in one line

No way was found to act in a workspace without current membership or a valid grant, to exceed the
owner-decided support scope, or for a connection-restricted member to read excluded-channel
conversation data. Real gaps were found around the edges (restricted admins' reach into workspace-wide
configuration, delayed-work corner cases, login hardening); each is fixed tests-first, except where
noted as an owner decision or an accepted limit.
